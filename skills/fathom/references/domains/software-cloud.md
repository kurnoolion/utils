# Domain pack — software development practice, cloud, platforms

## Primary sources (decide)
- Official docs, changelogs, release notes, deprecation notices, GitHub releases/issues/roadmaps, RFCs and IETF drafts.
- Incident post-mortems and status-page histories; pricing pages with Wayback history.
- Surveys with published methodology: DORA, Stack Overflow Developer Survey, JetBrains, CNCF (all self-selected; say so).
- Money: cloud segment results in hyperscaler earnings (growth, backlog, capex), SaaS 10-K/10-Q (net retention, cost of revenue).

## Secondary (frame, not decide)
Engineering blogs, conference talks (re:Invent, Google Cloud Next, Build, KubeCon), The Pragmatic Engineer, InfoQ, The New Stack; analyst quadrants (vendor-funded placement; treat as discovery).

## Expert vocabulary for queries
GA / preview / deprecated / end-of-life, LTS, semver, SLA and SLO, egress pricing, reserved and spot capacity, region and availability zone, DORA metrics, trunk-based development, feature flags, platform engineering, FinOps, SBOM, IaC drift.

## Signpost calendar
- Provider conferences: re:Invent (Dec), Next (Apr), Build (May), KubeCon (Apr, Nov) — pricing and GA announcements cluster here.
- Deprecation and EOL dates in official notices; LTS windows.
- Quarterly earnings for cloud growth and capex; pricing changes usually announced 30–90 days ahead.

## Pitfalls specific to this domain
- Vendor case studies and "adoption" claims come from the seller; weight accordingly.
- Preview features slip; "announced" is not "generally available".
- Deprecation is not removal; read the notice for the actual removal date.
- Benchmarks depend on configuration; demand the config before comparing.
- Survey percentages describe respondents, not the industry.
